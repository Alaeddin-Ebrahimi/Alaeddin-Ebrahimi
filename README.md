## 🚀 Now building: TrueBlue Scout

**[truebluescout.com.au](https://truebluescout.com.au)** is a live SaaS product I designed, built and run. It gives calm, facts-only tools to people working in Australia's National Disability Insurance Scheme (NDIS).

- **Plan Scout** helps plan managers and support coordinators look up NDIS providers against public registers (registration, compliance actions, ABN details), check a whole list at once, and get alerts when something on the public record changes.
- **Invoice check** lets you drop a PDF or a photo of an invoice. The text is read **in the browser** (pdf.js, plus tesseract.js OCR for photos and scans), so the invoice itself never leaves your device.
- **Market Scout** is NDIS market research by council area, built from published NDIA data.

**How it's built**

| Layer | Tech |
|---|---|
| Web app | Next.js + TypeScript on Cloudflare Workers |
| Data | Supabase Postgres with row-level security, pg_cron scheduled jobs, Deno Edge Functions |
| Ingestion | Python pipelines in GitHub Actions that load and refresh public register data |
| Payments and email | Stripe subscriptions and usage metering, Resend |
| Engineering | CI tests on every push, a decision log, rollback runbooks, architecture diagrams as code (Mermaid) |
